# Phase 2 Slice 1 Plan

## Goal

Start phase 2 by making word length a real gameplay mode and opening the app to a mode-selection screen before entering the puzzle.

## Scope

- Add four playable modes: 3, 4, 5, and 6 letters.
- Open first to a mode-selection screen.
- Preserve cached progress separately for each mode.
- Reuse the existing game flow inside each mode.
- Keep the result popup flow from phase 1.

## Notes

- This slice focuses on the architecture and UX for mode selection.
- The large curated 500-word dictionaries per mode remain a later phase 2 expansion item.
