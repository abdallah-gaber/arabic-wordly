# Phase 2 Slice 2 Plan

## Goal

Refine the phase 2 experience with stronger branding, a more helpful onboarding loop, and the first version of a hint system.

## Scope

- Rebrand the app to `خمنها` and `5amenha`.
- Apply the new app icon across Android, iOS, and web.
- Add timed hints that start immediately, then unlock again after configured waits.
- Keep hint state cached with the current puzzle on every platform.
- Refresh the public README and roadmap docs.

## Notes

- Hint timing should stay configurable because ads or rewarded unlocks may replace the current time gate later.
- The first hint version reveals a correct letter in the correct position to keep the rule engine simple and testable.
